# Project Steering

## ¿Qué es este proyecto?

TrazIA es un Visualizador de Arquitectura, que desarrollador ejecuta para que pueda entender un proyecto complejo en pocos minutos, sin tener que abrir decenas de archivos. En esencia, la aplicación "lee" el código y construye un mapa interactivo de cómo está organizado y cómo se relacionan sus componentes.

## Stack tecnológico

- Backend: Node.js/TypeScript
- Frontend: React + React Flow
- IA/ML: AWZ Bedrock
